# MoPlayer Pro TV clarity and navigation pass — 2026-11-06

## Verified cause and scope

The original bundled Manrope font is variable with a default weight of 200.
Registering that same resource as Medium/SemiBold/Bold in Compose did not choose
its weight axis: English screenshots showed hairline text even for headings.
Cairo defaults to 400. Static 500/600/700 instances now supply actual outlines
for both scripts across API 23+, without depending on variable-font support.
Original fonts are retained, with copyright and full SIL OFL notices in APK
assets. Optional regeneration uses scripts/fonts/instantiate-tv-fonts.py and
fontTools 4.68.0; no runtime or Gradle dependency was added.

## Implemented design

- All Material text roles now use the intended Latin/Arabic family, including
  previously unspecified small title/headline/display roles. TV secondary text
  has a 13sp floor; medium labels are 14sp. Primary content stays white with
  clearer muted metadata on neutral charcoal surfaces and orange brand accents.
- TV dock shows all seven section names with fixed-width targets; focus does not
  move neighboring labels. Phones retain their compact expanding navigation.
- TV dock sits inside the 5% bottom safe margin; content reserves enough room.
- Focus uses a controlled spring; glass and login transitions respond promptly.
  Short control feedback is distinct from costly continuous decoration on mid-tier TVs.
  Reduced-motion preference now reaches the root dock and login controls as well
  as browse screens. Root dock entrance/exit also respects reduced motion.
- Removed internal sorting keys from channel-card metadata; M3U index 0 is not
  presented as a provider channel number. The player's complete-list numbering
  is retained.
