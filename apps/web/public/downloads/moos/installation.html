MoOS للمكتب · Intel / AMD

افتح صفحة التنزيل للحصول على ISO المتحقق منه وملف توقيعه وبصمة SHA-256. قارِن البصمة وتحقق من التوقيع قبل كتابة الملف على USB. احتفظ بنسخة احتياطية لملفاتك، ثم أقلع من USB بوضع UEFI وراجع القرص المستهدف داخل المثبّت قبل تأكيد التثبيت.

Get the qualified ISO, detached signature and SHA-256 from the download page. Verify the checksum and signature before writing the USB. Back up your files, boot the USB in UEFI mode and review the target disk in the installer before confirming installation.

هذا الملف لنسخة المكتب x86-64؛ ليس ISO لنسخ NVIDIA أو Cloud أو ARM.

This is the generic x86-64 desktop ISO. It is not an NVIDIA, Cloud or ARM ISO.

MoOS · NVIDIA

نسخة NVIDIA صورة نظام موقّعة مستقلة. على جهاز MoOS NVIDIA مثبت، استخدم التحديثات أدناه. مسار التثبيت الأول أو التحويل من نظام آخر يحتاج دليلًا وتأهيلًا منفصلين؛ لا تعتبر ISO المكتب مثبّت NVIDIA ولا تستخدم سكربت التحويل القديم.

NVIDIA is a separate signed system image. Update an existing MoOS NVIDIA installation through the updater below. First installation or migration from another OS needs a separately qualified guide; the desktop ISO is not an NVIDIA installer. The retired conversion script does not install it.

MoOS Cloud

Cloud صورة x86-64 موقّعة مستقلة. تحديث محطة MoOS Cloud مثبتة يتم بأداة MoOS أدناه. تحويل خادم موجود يحتاج إثبات حفظ الوصول الإداري وسياسة التوقيع والتراجع؛ سكربت التحويل القديم متوقف، ولا يعدّل الخادم.

Cloud is a separate signed x86-64 image. Use the updater below on an existing MoOS Cloud machine. Migrating an existing server requires proof of retained administrative access, signature policy and rollback. The retired conversion script is disabled and changes nothing.

MoOS ARM64

ARM يستخدم صور QCOW2/UTM مستقلة. راجع دليل ARM وOracle وحدود الأجهزة المدعومة. ISO المكتب x86-64 لا يقلع على ARM.

ARM uses separate QCOW2/UTM images. Read the ARM and Oracle guide and its supported hardware limits. The x86-64 desktop ISO does not boot on ARM.

تحديث MoOS المثبت

افتح إعدادات النظام ← التحديثات، أو شغّل moai-do update في الطرفية. الأداة تجهّز الصورة الرسمية الموقّعة لنسختك. احفظ عملك ثم أعد التشغيل من واجهة الطاقة في MoOS لتطبيقها؛ تبقى النسخة السابقة للتراجع.

Open System Settings → Updates, or run moai-do update in your terminal. The updater stages the official signed image for your edition. Save your work and restart through the MoOS power interface to apply it; the previous deployment remains available for rollback.
